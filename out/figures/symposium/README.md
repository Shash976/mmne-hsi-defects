# Symposium figures

Generated by `make_symposium_figs.py` and `make_explore_figs.py` (run in the
`hsi` env from the repo root). Every number is read off disk — `data/samples.csv`,
`data/inventory_summary.json`,
`out/workflow/analyze/sio2_dish_white_20/{report.md, roi_evaluation.csv, cluster_comparison.csv, *_regions.csv}`,
`out/workflow/explore/sio2_bare_si+sio2_dish_white_20/{noise_metrics.csv, material_variance.csv}`,
`docs/audit-vs-objective.md` — or computed from the extracted piece cubes in
`out/workflow/extract/` and the raw scan.

All figures use the **live** dataset pair (`sio2_bare_si` + `sio2_dish_white_20`).
No figure depends on the retired `sio2_dish_black` preset.

## A finding worth stating out loud

The design spec expects bare Si to be spectrally homogeneous and processed SiO₂
more heterogeneous. On the live dataset the pipeline's own Stage-4 metric
(`material_variance.csv`) shows the opposite: SiO₂ mean spectral variance
**0.00065** vs silicon **0.00079**. What actually separates the populations is
*dispersion* — the SiO₂ pieces span a 4.8× range against 1.8× for the controls.

This is consistent with the extraction gap in `docs/audit-vs-objective.md`: the
shipped SAM masks isolate the uniform coloured oxide and clip the substrate, so
each SiO₂ "piece" is more homogeneous than the wafer it came from. Fig 02 and
fig 09 both state this rather than papering over it.

## Regenerating

```bash
conda run -n hsi python out/figures/symposium/make_symposium_figs.py
```

```bash
conda run -n hsi python out/figures/symposium/make_explore_figs.py
```

Delete `spectra_cache.npz` next to the script to force re-reading the piece cubes
(~24 cubes, a few minutes). `make_explore_figs.py` reads the raw scan from the
acquisition archive under `OneDrive - purdue.edu/Summer/HSI/sio2/`.
